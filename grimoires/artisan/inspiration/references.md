# Visual References — Echelon Redesign

## Source Analysis

### Pyth Network

**URL**: https://pyth.network
**Role**: Primary reference for data presentation + purple accent strategy

**Patterns Observed**:
- **Color**: Purple-forward (#6d28d9 primary, #8b5cf6 hover). Emerald green (#0ed28d) for success. Dark theme — invert for Echelon's light palette, keep the purple weight.
- **Typography**: Inter (variable 100-900) + Fragment Mono for code. Multi-weight hierarchy.
- **Spacing**: Grid-based, 1200px content width. 12/20/30/48px gap increments.
- **Density**: High. Stat cards combine large numbers + labels + line charts + percentage indicators.
- **Elevation**: Z-index layering (0-1002). Minimal shadows. Transparency overlays.

**Key Takeaways**:
- Purple as dominant accent works for fintech — conveys innovation without frivolity
- Stat card pattern: large number + small label + trend indicator is the standard
- Information density is achievable without clutter when typography hierarchy is strict

### Pyth Insights

**URL**: https://insights.pyth.network
**Role**: Reference for data tables, filter patterns, feed layouts

**Patterns Observed**:
- **Layout**: Vertical tab navigation (Overview / Publishers / Price Feeds). Featured content grid.
- **Color**: Purple for active states and directional indicators. Dark theme with high contrast.
- **Density**: Very high. Tables with inline badges, percentage changes, directional carets.
- **Interaction**: Tab-based filtering. Search across price feeds. Status badges (active/coming soon).

**Key Takeaways**:
- Tab + search + badge pattern is correct for Theatres page filtering
- Directional indicators (carets + percentage) should be standard for all market metrics
- Badge differentiation (active vs coming-soon) maps to Theatre status (LIVE/DRAFT/SETTLED)

### Kree8 Studio

**URL**: https://kree8.studio
**Role**: Reference for light theme execution, spacing, navigation

**Patterns Observed**:
- **Color**: Off-white background (#f5f5f5). Cyan/blue accent (#09f). Minimal palette.
- **Typography**: Geist + Euclid Circular B for headings, Inter for body. Multi-font (we take only the Inter approach).
- **Spacing**: Generous — 110px vertical padding, 32px horizontal. Breathing room.
- **Navigation**: Fixed top bar with backdrop blur + floating bottom bar at bottom:40px.
- **Elevation**: Soft shadows, subtle depth. Radial gradients at low opacity for background texture.

**Key Takeaways**:
- #f5f5f5 background is the right ballpark for Echelon (maps to ~oklch(0.965))
- Generous spacing works for landing/marketing but must be tightened for data surfaces
- Floating bottom bar pattern is relevant for mobile Echelon nav
- Backdrop blur on nav is decorative — Echelon uses solid backgrounds

### Parcl

**URL**: https://parcl.co
**Role**: Reference for analytics-first data platform on light theme

**Patterns Observed**:
- **Color**: Off-white (#fafafa, #f5f5f5). Multi-accent: emerald (#047857), blue (#2563eb), orange (#ea580c), purple (#7c3aed). Semantic reds/yellows.
- **Typography**: Inter + Inter Display (400-900 weights). Clean hierarchy.
- **Spacing**: 24-40px gaps. Generous padding but denser than Kree8.
- **Density**: High for an analytics platform. Data-first presentation.
- **Elevation**: Light shadows on cards. White cards on off-white background.

**Key Takeaways**:
- Multi-accent palette (purple + green + orange) validates Echelon's color direction
- White-on-off-white card separation is the correct elevation strategy
- Inter Display for large metrics is worth considering (but we stay with Inter variable weights)
- Analytics-first platforms can be light-themed and still feel serious
