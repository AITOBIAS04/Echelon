Empty States System
A shared component language for every empty surface in Echelon. Six state types, one anatomy, adapted by copy and tone across 13+ pages.
Component Spec
Anatomy & Slots
One component with five slots. Variants are in copy, tone, and which slots are populated — not in layout.
icon title description cta context

Slot Definitions

icon Page's own nav icon, rendered at 24-32px in a 48-56px container. Same icon the user sees in the sidebar. Never a novelty illustration.optional
title Short declarative statement. 2-5 words. "No theatres yet" not "Welcome to Theatres!" Describes the state, not the page.
description One sentence explaining what produces content here. Written in the page's voice (operational / intelligence / portfolio / archival).
cta Primary action button + optional secondary. The primary should be the most direct path to populating this page.optional
context Secondary information: status strip (All Clear), recent resolved items, skeleton structure, or dependency explanation.optional

Variant Rules

Zero State: icon + title + desc + CTA. Centered. Full-width within content area.
All Clear: status strip (context) + message (desc). No icon, no CTA. Strip is green-tinted.
Quiet Monitoring: skeleton (context) + overlay badge + message. Preserve spatial structure.
Sparse Data: chart shells (context) + inline note (desc). Keep visual scaffolding.
No Results: inline text + clear-filters CTA. Compact. Never full-page.
Not Yet Generated: icon + title + desc + trigger explanation (context) + CTA.
Key Distinction
Zero State vs All Clear
These must be visually distinguishable at a glance. Zero State is onboarding — the user hasn't started. All Clear is success — the system is working and nothing is wrong.

Visual Rules
Implementation Checklist
Do
Use the page's own nav icon at 24-32px
Keep empty states inside the existing content grid
Use status vocabulary: Healthy, Live, Settled, etc.
Make All Clear feel alive with recent-resolved items
Preserve map/graph skeletons in Quiet Monitoring
Keep No Results compact and inline
Explain what upstream event triggers content
Match copy tone to page role
Don't
Use novelty illustrations or mascots
Write "Nothing to see here" or "Oops!"
Make Zero State and All Clear look the same
Remove spatial structure from monitoring pages
Use full-page layout for No Results
Make empty states feel like errors
Add special empty-state art different from nav icons
Use exclamation marks or overly cheerful copy
